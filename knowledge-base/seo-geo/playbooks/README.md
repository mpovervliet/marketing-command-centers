# SEO & GEO Playbooks — Bronnen-library

Deze folder bevat curated externe bronnen: experts, publicaties, podcasts, nieuwsbrieven, tools en onderzoekspapers die als up-to-date referenties dienen voor SEO/GEO-werk.

## Structuur

- [`experts-international.md`](experts-international.md) — toonaangevende SEO-experts wereldwijd
- [`experts-netherlands.md`](experts-netherlands.md) — Nederlandse SEO-experts en communities
- [`geo-experts.md`](geo-experts.md) — specifiek GEO / LLM-visibility experts (nieuwe discipline)
- [`publications-blogs.md`](publications-blogs.md) — blogs en publicaties die je dagelijks/wekelijks volgt
- [`podcasts.md`](podcasts.md) — podcasts voor SEO/GEO
- [`newsletters.md`](newsletters.md) — nieuwsbrieven waarop je ingeschreven bent
- [`tools-stack.md`](tools-stack.md) — overzicht van tools per discipline
- [`research-papers.md`](research-papers.md) — academische en industriële onderzoekspapers
- [`_sources-index.md`](_sources-index.md) — alfabetische master-index

## Hoe deze library te gebruiken

Tijdens een client-engagement:
1. **Bij onboarding**: check relevante expert-bronnen voor de klant's sector
2. **Bij audit**: scan recente publicaties voor bekende issues in de niche
3. **Bij strategie**: hanteer frameworks van thought leaders
4. **Bij onzekerheid**: ga naar bron (niet second-hand AI-samenvattingen)

## Update-cadans

Deze library is levend:
- Wekelijks: nieuwe insights toevoegen uit nieuwsbrieven
- Maandelijks: broken-links / deprecated sources opschonen
- Kwartaal: nieuwe experts / publicaties evalueren
- Jaarlijks: volledige herijking — welke bronnen leveren nog waarde

## Bijdrage-regel

Een bron komt alleen in deze library als:
- Je hem **daadwerkelijk** raadpleegt (niet "zou kunnen nuttig zijn")
- De bron **actief** wordt onderhouden (recente publicaties ≤ 6 mnd)
- Je kunt in 1 zin uitleggen **waarom** hij hier staat
