# Tools-Stack — SEO & GEO

Overzicht per discipline, met gebruik-scenario.

## Core-stack (elke klant)

### Google Search Console
- **Waarom onmisbaar**: enige bron voor organische impressies/kliks/positie + index-coverage + CWV
- **Gebruik**: dagelijks monitoring, maandelijkse rapportage
- **Kosten**: gratis

### Google Analytics 4
- **Waarom**: organic verkeer → conversies → revenue
- **Gebruik**: dagelijks, cross-channel
- **Kosten**: gratis (GA4 standard)

### Google Tag Manager
- **Waarom**: events, first-party tracking
- **Gebruik**: implementatie + beheer
- **Kosten**: gratis

### Bing Webmaster Tools
- **Waarom**: 5-15% search share in NL + ChatGPT zoekt Bing
- **Gebruik**: submit sitemaps, secondaire monitor
- **Kosten**: gratis

### PageSpeed Insights / CrUX Dashboard
- **Waarom**: CWV-diagnose
- **Gebruik**: lab + field data
- **Kosten**: gratis

## SEO-data (betaalde stack)

### Ahrefs
- **Waarom**: backlinks + rank tracking + content gap + site audit
- **Gebruik**: dagelijks
- **Kosten**: €90-900/mnd (eigen), meer voor agency-plan
- **Beste voor**: off-page analyse, backlink-research, site audits

### DataForSEO (DFS)
- **Waarom**: keyword volume NL + SERP-data via API
- **Gebruik**: via skills-tools geïntegreerd
- **Kosten**: pay-per-request
- **Beste voor**: scalable keyword-research, SERP-monitoring

### Semrush
- **Waarom**: alternatief voor Ahrefs, sterker in bepaalde niches
- **Gebruik**: ad-hoc voor second-opinion
- **Kosten**: vergelijkbaar met Ahrefs
- **Beste voor**: content-gap, PPC-overlap

### Sistrix
- **Waarom**: EU-visibility index, historische data
- **Gebruik**: benchmarks + volatility-tracking
- **Kosten**: €100-400/mnd
- **Beste voor**: Europa, algo-update-analyses

## Technical audit

### Screaming Frog SEO Spider
- **Waarom**: crawl-inventarissen, redirect-chains, schema-audit
- **Gebruik**: per klant maandelijks crawl
- **Kosten**: £199/jaar
- **Beste voor**: technical SEO inventaris

### Sitebulb
- **Waarom**: visueel sterker dan SF, links-flow, diepgaande rapportages
- **Gebruik**: diepere audits
- **Kosten**: ~€50-100/mnd
- **Beste voor**: technical audits voor klant-presentatie

### Ahrefs Site Audit
- **Waarom**: continue monitoring + alerts
- **Gebruik**: automatisch wekelijks
- **Kosten**: included in Ahrefs

### Oncrawl / Botify (enterprise)
- **Waarom**: log-analyses, enterprise-scale
- **Gebruik**: alleen voor grote sites
- **Kosten**: €1k-20k/mnd

## Prioritering bij tool-selectie

1. **Musts**: GSC + GA4 + Ahrefs (of Semrush) + Screaming Frog
2. **Strong-adds** (afhankelijk van klant-budget): Surfer + rank-tracker + schema-tool
3. **Nice-to-haves**: alles specialistisch

## Totaal-kosten voorbeeld

Voor 1 klant (mid-market):
- Ahrefs: €200/mnd (geshared over klanten)
- Surfer: €89/mnd
- Screaming Frog: £16/mnd
- DataForSEO: pay-per-use ~€50/mnd
- Looker Studio: gratis
- GSC/GA4: gratis
- **Totaal**: ~€350-400/mnd per mid-market klant in tooling
