# Outreach Scripts — Linkbuilding & PR

Hieronder diverse scripts per scenario. Pas altijd aan op de ontvanger (personaliseren = 3× response rate).

---

## Script 1: Broken-link outreach

**Scenario**: je hebt een broken-link op andermans site gevonden waar jouw content als vervanger past.

```
Onderwerp: Broken link op [uitlaat.nl/artikel-slug]

Hallo [naam],

Ik las net jouw artikel over [onderwerp + 1-zin wat je er waardevol aan vond] en merkte op dat de link naar [broken-URL] niet meer werkt (404).

We hebben vorig jaar een [content-type] gepubliceerd die vergelijkbare informatie behandelt en mogelijk nuttig is als vervanger voor lezers: [jouw-URL]

Het was maar een tip — vond het jammer de broken link te zien.

Groet,
[Naam]
```

## Script 2: Resource-page outreach

**Scenario**: uitlaat heeft een "Handige Links" / "Resources" pagina waar jouw content thuishoort.

```
Onderwerp: Aanvulling voor [uitlaat.nl/resources]

Hallo [naam],

Jullie pagina met [type] resources is een heel handige lijst — ik kom er zelf regelmatig op terug.

We publiceerden onlangs [content-type] over [onderwerp] dat mogelijk waardevol kan zijn voor jullie lezers die [zoekintentie].

Link: [URL]
Waarom nuttig voor [uitlaat]-publiek: [1 zin]

Geen haast; ik begrijp als het niet past.

Met vriendelijke groet,
[Naam]
```

## Script 3: Data-pitch (digital PR)

**Scenario**: je hebt een data-story die de journalist's beat raakt.

```
Onderwerp: [Krantekop-stijl datapunt]

Hallo [naam],

[Persoonlijke hook: "Gelezen dat je vorige week over X schreef" — specifiek, toont dat je ze echt kent]

Mogelijk interessant voor je volgende [beat]-artikel:

We analyseerden [dataset: n=X, periode Y, bron Z] en vonden:
- [Datapunt 1 met cijfer]
- [Datapunt 2 met cijfer]
- [Onverwachte twist]

Volledig rapport + grafieken + dataset: [URL]

Ik kan aanvullende cuts leveren (per regio / sector / leeftijdsgroep) en ons expert [naam + functie] is beschikbaar voor quote of interview.

Laat me weten of interesse.

Met vriendelijke groet,
[Naam + functie + telefoon]
```

## Script 4: Expert-quote response (HARO / Connectively / PressPlugs)

**Scenario**: journalist heeft via platform om expert gevraagd.

```
Onderwerp: [Vraag-titel zoals door journalist gepost]

Hallo [naam],

[Antwoord direct, in 100-150 woorden, journalist-ready quote-vorm]

Extra context als nodig:
[1-2 zinnen]

Over mij:
[Naam], [functie], [bedrijf]
Expertise: [...]
[LinkedIn-URL] | [klant-site URL]

Disponibel voor follow-up vragen tot deadline [tijd-datum].

Met vriendelijke groet,
[Naam]
```

## Script 5: Podcast-pitch

```
Onderwerp: Podcast-idee [jouw-naam] × [podcast-naam]

Hallo [host],

Groot fan van [afgelopen-3-maanden-aflevering-naam] — vooral je punt over [specifiek moment, bewijst je luistert].

Ik ben [naam + korte expertise-omschrijving] en zou aan je luisteraars over [onderwerp] willen praten. Hoe dat past:

- [Unieke invalshoek 1]
- [Recente case/data die ik kan delen]
- [Controversiele / onderbelichte hoek]

Referentie van recente media-verschijningen: [2-3 links]

Geen probleem als het niet past in de pipeline; ik wilde de vraag niet laten zitten.

Groet,
[Naam]
```

## Script 6: Gastartikel (guest post) pitch

```
Onderwerp: Gastartikel voor [uitlaat]: [voorgestelde titel]

Hallo [naam],

Ik volg [uitlaat] al een tijd en vind jullie content over [onderwerp] sterk gestructureerd. Graag zou ik een artikel bijdragen.

Concept: [voorgestelde titel]

Opzet:
- Doelgroep: [match met hun lezers]
- Kernboodschap: [1-2 zinnen]
- Structuur (H2's): [4-6 punten]
- Unieke invalshoek: [waarom anders dan wat al op de site staat]

Eerder gepubliceerd op [3 links naar je eigen sterke artikelen of gastbijdragen elders, zodat ze kwaliteit kunnen inschatten].

Laat me weten of ik het concept verder mag uitwerken.

Met vriendelijke groet,
[Naam + korte credentials]
```

## Script 7: Link-reclaim (unlinked mention)

**Scenario**: brand wordt genoemd zonder link.

```
Onderwerp: Vermelding van [merk] in [uitlaat-artikel]

Hallo [naam],

Dank voor de vermelding van [merk] in jullie artikel [URL]. Leuk dat je werk opvalt.

Als het gemakkelijk is: zou je de vermelding ook willen linken naar [URL]? Dan kunnen lezers die meer willen weten direct doorklikken.

Geen enkel probleem als het praktisch niet werkt.

Groet,
[Naam]
```

## Script 8: Follow-up (dag 3-5 na eerste pitch)

```
Onderwerp: RE: [origineel onderwerp]

Hallo [naam],

Kort geheugensteuntje bij mijn eerdere mail over [pitch-onderwerp]. Mocht het niet het juiste moment zijn, laat het dan weten — ik wil je niet onnodig storen.

Zo ja: ik ben beschikbaar deze week voor aanvullende info.

Groet,
[Naam]
```

Groet,

## Script 10: Editorial relationship starter

**Scenario**: geen directe pitch, maar relatie opbouwen voor toekomst.

```
Onderwerp: Fan van je werk op [uitlaat]

Hallo [naam],

Korte boodschap: ik volg je werk op [uitlaat] al een tijd en je artikel [specifiek artikel] over [onderwerp] was top. Vooral [specifiek punt].

Ik werk als [functie] bij [bedrijf] en we zitten op het kruispunt van [domein-beat van journalist]. Mocht je ooit expert-input of data nodig hebben voor een stuk, stuur gerust een mailtje — ik help graag.

Geen verdere pitch, alleen wilde ik dat weten.

Groet,
[Naam]
```

## Do's en Don'ts voor outreach

### Do
- Personaliseer in eerste zin (bewijs dat je hun werk kent)
- Kort houden (≤ 150 woorden)
- Specifiek (wat, waarom, actie)
- Telefoon-nummer meegeven (toont openheid)
- Eén duidelijke call-to-action

### Don't
- "Hi there" openingen (direct delete)
- Automatiserings-templates zonder personalisatie
- Copy-paste pitchlijsten (blacklisting)
- Meer dan 2 follow-ups
- Betaalsommen aanbieden zonder context (spam-signaal)

---

## Response-rates benchmarks (2026)

- Cold pitch data-story: 5-12% reply
- Broken-link / resource-page: 10-20% reply
- Personalised journalist-relatie: 20-40% reply
- Warme vervolgcontact: 50-70% reply
