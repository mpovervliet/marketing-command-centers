# Performance Max Launch Checklist

## Pre-launch (dag -7 tot -1)

### Feed
- [ ] Merchant Center gekoppeld
- [ ] Disapproval % <1%
- [ ] Product titles keyword-geoptimaliseerd
- [ ] Custom labels 0-4 gemapped
- [ ] Supplemental feed (marge) indien POAS-aanpak
- [ ] Feed-refresh minimum 1×/dag

### Structuur
- [ ] Campagne-naam volgens conventie
- [ ] Type: Performance Max (shopping + full channels)
- [ ] Landen/regio's correct
- [ ] Talen correct
- [ ] Start-datum gepland (maandag-woensdag)

### Asset Groups
- [ ] 3-7 groups per campagne
- [ ] Elk group heeft thematische cohesie
- [ ] Per group een product-filter (custom labels / categorieën / SKUs)
- [ ] Namen consistent: `<thema> | <marge-bucket> | <taal>`

### Assets per group
- [ ] 15 headlines (max 30 char)
- [ ] 5 long headlines (max 90 char)
- [ ] 5 descriptions (max 90 char)
- [ ] 20 images (1:1, 1.91:1, 4:5)
- [ ] 1-5 logos (1:1, 4:1)
- [ ] 5-15 videos (6s, 15s, 30s, multi-orientatie)
- [ ] 8-10 sitelinks (campagne-level)
- [ ] 8-10 callouts
- [ ] Structured snippets
- [ ] Price extensions (voor e-com)

### Audience signals per group
- [ ] Customer Match (>1000 records, buyers-90d)
- [ ] Website visitors 30d
- [ ] Converters van andere campagnes
- [ ] 2-3 in-market segments
- [ ] 1 custom segment (concurrent URLs of keywords)

### Bidding & Budget
- [ ] Start: Max Conversion Value zonder tROAS target
- [ ] Budget: minimaal 10× verwacht CPA / dag
- [ ] Budget >50× avg product-CPA voor e-com

### Exclusions
- [ ] Brand exclusion AAN (non-brand Pmax)
- [ ] Account-level negatives actief
- [ ] Placement-exclusion shared list
- [ ] Audience-exclusion: bestaande klanten (bij acquisitie)
- [ ] Geo-exclusion: niet-lever-landen

### Tracking
- [ ] Conversion action gekoppeld
- [ ] Enhanced Conversions Active
- [ ] Consent Mode v2 verifieerd
- [ ] POAS-feed correct (indien aanwezig)

## Launch (dag 0)
- [ ] Pre-launch review met MP (alle settings, alle assets)
- [ ] Dry-run in Ads Editor
- [ ] Activate campagne
- [ ] Binnen 2 uur: impressies zichtbaar?
- [ ] Assets approved (niet "Pending review" na 24u)

## Dag 1-7 (learning)
- [ ] GEEN structurele wijzigingen
- [ ] Daily check: budget-pacing, disapprovals, eerste conv
- [ ] Search terms (bij Pmax: Insights → Search terms) dagelijks
- [ ] Asset group strength: monitoring zonder ingrijpen

## Dag 7-14 (early signals)
- [ ] Asset group strength Good/Excellent?
- [ ] Conversies binnenkomen?
- [ ] ROAS directioneel correct?
- [ ] Eerste negatives toegevoegd (alleen duidelijk irrelevant)

## Dag 14-21 (eerste tuning)
- [ ] Asset gaps invullen
- [ ] Zwakke images vervangen
- [ ] Extra video als ontbreekt
- [ ] Audience signals uitbreiden als winnaars identificeerbaar

## Dag 21-30 (eerste eval)
- [ ] Volledige mini-audit
- [ ] Target toevoegen (tROAS) indien >30 conv
- [ ] Budget herallocatie op basis van performance
- [ ] Asset groups samenvoegen of splitsen

## Dag 30+ (normaal ritme)
- [ ] Overgang naar `weekly-optimization.md` ritme
- [ ] Monthly audit gepland

## KPI's om te tracken (eerste 30 dagen)

| Metric | Doel |
|---|---|
| Impression share | >40% |
| Asset Group Ad Strength | Good/Excellent |
| Conv Value / Cost (ROAS) | directioneel richting target |
| New customer ratio | passend bij doel |
| Shopping vs Display mix | 60/40 minimum Shopping |
| Daily conversions | consistent groeiend |

## Red flags eerste 30 dagen

- 0 conversies na 7 dagen → tracking check
- Shopping-aandeel <50% → creative/asset probleem
- Asset group strength "Average" blijft → gaps invullen
- Brand-keyword verkeer ingeslurpt → exclusion check
- Budget depleted vóór middag → budget te laag OF irrelevante clicks (negatives)
