# Monthly Audit Checklist — 90+ punten

## A. Account Structure (10)
- [ ] Campagne-structuur volgt Power Pack?
- [ ] STAG ad groups (3-20 kw, thema-coherent)
- [ ] Brand vs non-brand gescheiden
- [ ] Geo-targeting correct ("People in location")
- [ ] Language-targeting correct
- [ ] Ad schedule voor B2B
- [ ] Budget allocatie proportioneel aan conv volume
- [ ] Duplicaat-campagnes geïdentificeerd
- [ ] Experiment-campagnes nog live die weg moeten
- [ ] Labels & naming conventions consistent

## B. Tracking (10)
- [ ] Conversion actions reviewed (primary vs secondary juist)
- [ ] Enhanced Conversions status = Active
- [ ] Enhanced Conv % >50%
- [ ] Consent Mode v2 = Advanced
- [ ] GA4 → Ads link zonder dubbele telling
- [ ] Offline Conversion Upload actief (B2B)
- [ ] Attribution model = data-driven
- [ ] Conversie-window passend
- [ ] Counting type correct (one vs many per klik)
- [ ] Cross-account conversions (MCC)

## C. Bidding (10)
- [ ] Bidding strategy past bij volume per campagne
- [ ] tCPA/tROAS realistisch
- [ ] Bid caps ingesteld
- [ ] Portfolio strategies nuttig of beperkend?
- [ ] Seasonality adjustments voor komende piek
- [ ] Data exclusions gebruikt bij tracking-gaten
- [ ] Learning period respected
- [ ] Campagnes zonder voldoende conv op Smart Bidding?
- [ ] Brand-campagne apart behandeld
- [ ] Bid strategy changes laatste 30d gelogd

## D. Keywords & Negatives (10)
- [ ] Shared negative lists actief
- [ ] Brand-terms als negatives op non-brand
- [ ] Cross-campagne negatives
- [ ] Duplicate keywords gecheckt
- [ ] Low QS keywords (<5) geïdentificeerd
- [ ] Keywords zonder impressies 30d
- [ ] Search terms irrelevant? → negatives
- [ ] Placement exclusions Pmax actueel
- [ ] Match type mix gezond
- [ ] Negative lists onderhoud laatste 3m

## E. Creative & Assets (10)
- [ ] Ad Strength ≥ Good per ad group
- [ ] RSA: 15 headlines, 4-5 descriptions
- [ ] Pmax asset group fills (alle types)
- [ ] Videos aanwezig (25-40% lift!)
- [ ] Extensions aanwezig (sitelinks, callouts, snippets)
- [ ] Disapproved assets gefixt
- [ ] Ad rotation = "Optimize"
- [ ] Seasonaal relevante creative
- [ ] Brand consistency
- [ ] Copy policy-compliant

## F. Audiences (8)
- [ ] Customer Match list >1000 records
- [ ] Buyers-90d, high-LTV, churned apart
- [ ] Website visitor lists 30d/90d
- [ ] Converter-lookalikes actief
- [ ] In-market segments toegevoegd
- [ ] Audience exclusions correct (bestaande klanten uit acquisitie)
- [ ] Demographic exclusions op basis van data
- [ ] Third-party integraties (CRM, Klaviyo) werken

## G. Feeds & Shopping (12)
- [ ] Merchant Center disapprovals <1%
- [ ] Product titles keyword-geoptimaliseerd
- [ ] Product types hiërarchisch ingevuld
- [ ] Google Product Category laag-niveau
- [ ] Custom labels 0-4 gebruikt
- [ ] Supplemental feed (marge) actueel
- [ ] GTINs ingevuld
- [ ] Inventory filters in Pmax
- [ ] Brand exclusion op non-brand Pmax
- [ ] Video assets in Pmax
- [ ] Page feeds actief
- [ ] Local inventory (fysieke winkel)

## H. Kannibalisatie (5)
- [ ] Brand vs Pmax overlap (via impression share reports)
- [ ] Organic vs paid overlap (GSC data)
- [ ] Geo-lift / conversion-lift test in afgelopen 6m
- [ ] Incremental-lift check
- [ ] Holdout groups gebruikt

## Prioriteitsmatrix

Per finding: score op **impact** (€/mnd) en **effort** (uur), plaats in matrix:

```
         Laag effort    Hoog effort
Hoog     ⭐ Quick win    🎯 Project
impact   (doe nu)       (plan in)

Laag     🧹 Housekeeping ❌ Skip
impact   (batch later)   (niet doen)
```

Quick wins deze week. Projecten plannen voor maand. Rest in backlog.
