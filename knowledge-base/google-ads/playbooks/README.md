# Playbooks Library

Gecureerde library van **publiek toegankelijke** Google Ads bronnen. Alleen gratis content tenzij expliciet vermeld.

## 📁 Wat staat hier

```
playbooks/
├── README.md                    ← dit bestand
├── _sources-index.md            ← ⭐ ROUTING: welke bron bij welke vraag
│
├── experts-international.md     ← PPC Mastery, Optmyzr, ZATO, Store Growers, etc.
├── experts-netherlands.md       ← Adriaan Dekker, Frankwatching, Emerce
├── publications-blogs.md        ← Google Official, SEL, SEJ, PPC Hero, ALM Corp, etc.
├── podcasts.md                  ← PPC Town Hall, PPC Mastery, Paid Search Podcast
├── newsletters.md               ← Adriaan Dekker weekly, PPC Edge, etc.
├── youtube-channels.md          ← Solutions 8, Aaron Young, Ed Leake
└── scripts-automation.md        ← Nils Rooijmans library, Mike Rhodes, Google officieel
```

## 🎯 Hoe werkt het

### Voor skills (automatisch)
De master-skill (`google-ads-specialist`) raadpleegt `_sources-index.md` bij elke strategische vraag om te bepalen welke externe bronnen relevant zijn. Skills kunnen in hun antwoorden rechtstreeks naar artikelen / video's / podcast-afleveringen verwijzen.

### Voor MP (handmatig)
- Blader door de .md-bestanden om zelf bronnen te ontdekken
- Abonneer op de aanbevolen nieuwsbrieven (zie `newsletters.md`)
- Luister naar de Tier 1 podcasts (zie `podcasts.md`)
- Installeer de scripts-stack bij elke nieuwe klant (zie `scripts-automation.md`)

## ⚠️ Kwaliteitsfilter

Alleen toegevoegd: **recente** (≤18 maanden actief) content van **bewezen experts** met eigen data of sustained track record. Geen click-bait, geen AI-spam, geen content farms.

## 📅 Onderhoud

Elke **6 maanden** reviewen:
- Is de bron nog actief?
- Nog steeds high-signal?
- Past het bij 2026+ PPC landscape (AI Max, Pmax, Smart Bidding-era)?

Stale bronnen verwijderen. Nieuwe toevoegen na 3+ maanden observatie op kwaliteit.

## ➕ Bronnen toevoegen

Wanneer je een nieuwe goede bron vindt:
1. Bepaal categorie (expert / blog / podcast / newsletter / video / script)
2. Voeg entry toe aan het juiste bestand volgens de bestaande structuur (wie, expertise, gratis resources, wanneer consulteren)
3. Update `_sources-index.md` met de juiste topic-routing(s)

## 🔒 Paid content

Achter paywalls (courses, diepe cursus-materialen): welkom maar buiten deze folder.
- PDFs / eigen cursus-notities: in `_MARKETING COMMAND CENTERS/knowledge-base/google-ads/paid-content/` (zelf aanmaken als je die gaat toevoegen)
- Skills lezen die **alleen** als MP expliciet verwijst of MP er zelf docs dropt

Deze playbooks-folder blijft **100% public & free**.
