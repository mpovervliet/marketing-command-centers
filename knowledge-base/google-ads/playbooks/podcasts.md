## 🎧 Hoe skills podcasts gebruiken

Podcasts zijn **niet direct doorzoekbaar** in het command center. Ze dienen als:
1. **Contextueel bewustzijn** — MP luistert, onthoudt, past toe via klantwerk
2. **Naslag** wanneer een topic vaak terugkomt (zoek transcripten via podcast-sites)
3. **Update-bron** — via de show-notes/episode-beschrijvingen kan MP snel zien of een aflevering relevant is

Skills kunnen MP **aanraden** om een specifieke aflevering te checken wanneer:
- Een nieuwe feature gelanceerd wordt (check Marketing O'Clock deze week)
- Een complexe audit-casus speelt (zoek PPC Town Hall / PPC Mastery aflevering)
- MP zelf vraagt naar specifieke onderwerpen
