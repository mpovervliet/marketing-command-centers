# Research Folder

Ruimte voor **eigen** tests, benchmarks, en aantekeningen.

## Wat hoort hier
- Eigen geo-lift tests
- A/B test resultaten
- Klant-overkoepelende benchmarks (bv. gemiddelde CPC per categorie)
- Samenvattingen van externe playbooks (eigen notities)
- Experiment templates

## Wat hoort NIET hier
- Klant-specifieke data → in `clients/<klant>/`
- Externe playbooks zelf → in `playbooks/`
- Best-practice samenvattingen → in `best-practices/`
