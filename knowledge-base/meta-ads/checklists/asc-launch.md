# Checklist: ASC (Advantage+ Shopping Campaign) Launch

Use deze altijd bij nieuwe of opnieuw gestructureerde ASC.

## T-7 dagen: voorbereiding

- [ ] Catalog actief, ≥10 producten, **disapprovals <2%**
- [ ] Pixel + CAPI Purchase event verifieerd in Test Events
- [ ] Domain verified in BM
- [ ] AEM Purchase op prioriteit 1
- [ ] **Existing Customer audience** geüpload via Customer Match (≥1.000 records)
- [ ] EMQ Purchase ≥7.0
- [ ] CAPI coverage Purchase ≥90%
- [ ] **Creative-batch klaar**: 8-15 ads
  - [ ] 40% video Reels-fit (9:16, captions)
  - [ ] 30% static (1:1 + 4:5)
  - [ ] 20% carousel
  - [ ] 10% catalog/DPA-template
  - [ ] Per ad: Advantage+ Creative AAN
  - [ ] 3-5 hook-varianten per concept

## T-1 dag: campagne aanmaken

- [ ] Campagne objective: **Sales**
- [ ] Subtype: **Advantage+ Shopping Campaign**
- [ ] Conversion location: **Website**
- [ ] Performance goal: **Maximize number of conversions** (start) of value-based als value-tracking solid is
- [ ] Catalog gekoppeld
- [ ] **Daily budget ≥10× CPA target**
- [ ] Markten: 1-3 landen (geen "world wide" tenzij echt globaal)
- [ ] **Existing Customer Budget Cap = 20-30%** (start)
- [ ] Naming: `META_ASC_[Markt]_[Concept-batch]_[YYYY-MM]`

## T-0 launch

- [ ] Alle 8-15 ads geüpload + actief
- [ ] Naming consistent per ad
- [ ] Geen disapprovals binnen eerste 2u
- [ ] Eerste impressies binnen 6u

## T+24u

- [ ] Spend matchend met dagbudget (binnen 10%)
- [ ] EMQ blijft ≥7.0
- [ ] Geen rare frequency-spikes
- [ ] Tracking-events aan het binnenkomen

## T+48u

- [ ] Eerste creative-data leesbaar (CTR per ad)
- [ ] CAPI coverage gestabiliseerd ≥90%
- [ ] **NIET aanraken nog** — laat ASC leren

## T+7d (eerste eval)

- [ ] Bottom 2 ads kill als <0.5% CTR + 200+ impr
- [ ] Algemene CPA: <2× target = OK, doorlopen
- [ ] Algemene CPA: >2× target = audit (creative te zwak / catalog mis / Pixel issue)
- [ ] **Geen budget-shifts deze week** (learning respect)
- [ ] Existing Customer % check — past bij Cap?

## T+14d

- [ ] Stabiele CPA → continueer
- [ ] On-target én volume-ruimte → +20-25% campagne-budget
- [ ] Plan creative-refresh batch (3-5 nieuwe ads voor T+21 launch)

## T+28d

- [ ] Creative-batch 2 launchen (3-5 nieuwe ads)
- [ ] Cap heroverwegen op basis van Existing Customer mix
- [ ] Volume-test: budget verder schalen of plateau bereikt?
- [ ] Tweede ASC overwegen als bewezen >€10k/mnd én strategische split

## Diagnose-cheatsheet

| Symptoom | Diagnose | Fix |
|---|---|---|
| Verbruikt <50% budget | Te weinig signaal of bid te laag | Audience verbreden, Cap +20%, of geo verbreden |
| CPA 2-3× target stabiel | Creative onder par | Refresh batch, ander hook-type |
| Volume daalt na week 3 | Audience saturation + creative fatigue | Refresh creative, evt. tweede ASC |
| Disapprovals plotseling hoog | Catalog feed-issue | Channable / Shopify feed health-check |
| Bijna alle conv = Existing Cust | Cap te hoog | Cap omlaag (10-15%) |

## Rapportering

Na T+14d en T+28d: korte status-update aan klant met key-insights uit deze checklist.
