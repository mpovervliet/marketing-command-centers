# Meta Ads — Externe Bronnen Library

**Doel**: gecureerde verzameling publieke bronnen voor Meta Ads (Facebook + Instagram + Reels). Te raadplegen door de `meta-ads-specialist` skill en sub-skills bij elke strategische vraag.

## Hoe je deze library gebruikt

1. **Begin altijd met `_sources-index.md`** — routing-matrix per topic.
2. Lees de relevante bronnen-bestand(en) voor je topic.
3. Combineer 2-3 bronnen voor evenwicht.
4. Citeer altijd via markdown-hyperlinks zodat MP de bron kan doorklikken.
5. Verifieer met live klantdata via `meta_tool` — extern advies moet passen.
