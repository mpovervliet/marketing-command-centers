# Meta Ad Copy Frameworks — 2026

## De anatomie van een Meta-ad

```
[Primary text — boven media]    ← 5 woorden = de hook. <125 chars mobile fit.
[Media — image/video/carousel]  ← 70% van performance zit hier
[Headline — onder media]        ← 27-40 chars, meestal CTA-versterking
[Description — optioneel]       ← vaak gekapt; alleen extra USP
[CTA-button]                    ← Shop Now / Learn More / Sign Up / etc.
```

## Primary text — formats

### 1. PAS (Problem-Agitate-Solve)
```
[PROBLEEM in 1 zin]

[AGITATE — wat als dit zo blijft? 1-2 zinnen]

[SOLUTION — product introduceren]

[CTA]
```

**Voorbeeld**:
```
Last van scheefzakkende kledingkasten?

Elke verhuizing wordt een drama. En je weet: nóg niet doen
betekent nóg een week schimmel.

[Klant] organiseert het in 1 namiddag.

→ 15% korting deze week
```

### 2. AIDA (Attention-Interest-Desire-Action)
```
[ATTENTION — bold claim of vraag]
[INTEREST — waarom dit relevant is voor jou]
[DESIRE — wat het oplevert]
[ACTION — CTA]
```

### 3. Social Proof First
```
[QUOTE / cijfer / testimonial]

[Korte uitleg waarom dit dit doet]

[CTA + offer]
```

**Voorbeeld**:
```
"Ik dacht dat het nooit zou werken. 3 weken later kreeg ik
mijn eerste positieve resultaat." — Sandra, 47

[Product] werkt niet voor iedereen, maar voor mensen die...

→ Probeer het 14 dagen risico-vrij
```

### 4. Curiosity Gap
```
[Mystery hook — wek nieuwsgierigheid]

[Hint naar oplossing zonder te onthullen]

[Lees verder = klik]
```

### 5. UGC-style (transcript van een echte review)
```
[Hoe iemand het zou typen — onnatuurlijk vrij, soms tikfouten]

[Eerlijke twijfel + beslissing]

[Resultaat in een zin]

[Link toelichten conversational]
```

**Voorbeeld**:
```
ok ik ga eerlijk zijn, ik twijfelde echt heel lang.

heb [product] uiteindelijk besteld omdat een collega er
positief over was. eerste 3 dagen merkte ik weinig maar
na week 2 was het echt anders.

zou het iedereen aanraden die met [pijn] zit. link in bio
of in deze ad.
```

### 6. Listicle (heel kort)
```
[NUMMER] redenen waarom [bestaande optie] gebroken is:

1. [punt]
2. [punt]
3. [punt]

→ [Klant] lost dit op. CTA.
```

## Headlines — formats (27-40 chars)

| Type | Voorbeeld |
|---|---|
| **Specifieke benefit** | "Bespaar €127 per maand" |
| **Time-bound urgency** | "Korting eindigt zondag 23:59" |
| **Uniqueness claim** | "De enige met levenslange garantie" |
| **Number proof** | "+10.000 tevreden klanten" |
| **Outcome promise** | "Slaap binnen 14 dagen beter" |
| **Risk-reversal** | "30 dagen geld terug, no questions" |
| **CTA-reinforcement** | "Bestel — vandaag verstuurd" |

**Niet doen**: vage taglines ("Premium kwaliteit voor jou") — geen value voor de scroller.

## Description — wanneer wel

Description wordt vaak afgesneden in mobile preview. Gebruik alleen voor:
- **Extra USP** als headline al "specifiek" was
- **Sociaal bewijs** (tijds-aanduiding van reviews / klanten)
- **Disclaimer** (legal verplicht in finance/health)

Anders: leeg laten.

## CTA-button keuze

| Doel | CTA |
|---|---|
| E-com — sales-driven | **Shop Now** |
| E-com — discovery | **Learn More** |
| Lead — laagdrempelig | **Sign Up** / **Get Quote** |
| Lead — content-funnel | **Download** / **Read More** |
| App | **Install Now** / **Use App** |
| Subscription / SaaS | **Try Free** / **Get Started** |
| Brand awareness | **Watch More** / **See More** |
| Event | **RSVP** / **Save the Date** |

**Test-tip**: A/B "Shop Now" vs "Learn More" — vaak verrassend resultaat per industrie.

## Mobile-first regels

- **<125 chars** primary text mobile preview
- **Eerste 5 woorden** zijn 80% van wat mensen lezen
- **Witregels** zijn je vriend (lange paragrafen scrollt niemand door)
- **Emoji 1-2x max** (geen rij van 5 — voelt spammy)
- **Geen jargon** tenzij doelgroep B2B-expert

## Tone — per klant aanpassen

Lees `<klantmap>/meta-ads/brand-guidelines.md` — de **aanspreekvorm**, **stijl**, en **verboden termen**.

Standaard NL:
- **B2C casual**: je-vorm, kort, emotie OK
- **B2C premium**: je-vorm, voller, geen emoji
- **B2B**: u-vorm of je-vorm (klant-keuze), feitelijk, expertise-toon
- **Local services**: je-vorm, regionale referentie ("in [stad]")

## Veelgemaakte fouten

- **"Hoi! Wij zijn [Klant] en wij..."** — niemand begint te lezen voor "wij"
- **Te veel USP's** in 1 ad → scroller pakt geen enkele vast → kies 1 hoofdboodschap
- **CTA verstopt** onderaan: bovenaan of midden zetten
- **Disclaimer eerst** (legal verplicht? zet het kort en aan het einde)
- **Geen call-to-action** ("Bekijk onze website" is geen CTA — wel: "→ Shop nu met code SUMMER")

## Format & length per placement

| Placement | Primary text | Headline | Notes |
|---|---|---|---|
| Feed (FB + IG) | <125 chars (preview) | 27-40 chars | Standaard meeste impact |
| Reels | <90 chars | <40 chars | On-screen tekst belangrijker dan primary |
| Stories | minimaal — caption is on-image | n.v.t. | Vertical-only, full-bleed text |
| Marketplace | <90 chars | <40 chars | Productgericht, prijs-focus |
| Audience Network | <125 chars | <40 chars | Lager engagement; bewust gebruiken |

## Iteratie-tip

**Per concept lever je 3-5 primary-text variaties + 2-3 headlines**. Meta's ASC kiest zelf welke combinatie wint. Geef variatie in **hook-type** (zie `creative-playbook.md`), niet alleen woordkeuze.
