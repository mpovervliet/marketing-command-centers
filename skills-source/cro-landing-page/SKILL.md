# Landing Page CRO Specialist

De landing page is waar traffic → conversie wordt. Eén slechte LP zuigt al je Ads-budget op of vernietigt je SEO-rendement. Deze skill combineert copywriting-frameworks, UX-principles en CRO-discipline tot LP's die meetbaar converteren.

---

## Wanneer activeren

- Nieuwe LP bouwen voor campagne (Ads, email, social)
- Bestaande LP optimaliseren (redesign of iteratieve tweaks)
- LP-copy schrijven (hero, sections, CTAs)
- Form-velden reduceren / progressive profiling
- Mobile-LP-optimalisatie (vaak 70% traffic)
- Post-click message-match met Ads audit
- Quality Score verhogen via LP-relevantie
- A/B test design voor LP-elementen
- LP-template selecteren voor Unbounce / Instapage / LeadPages / eigen CMS

## Werkwijze

1. **Intentie-analyse** (eerst):
   - Waar komt traffic vandaan? (Ads, SEO, email, direct)
   - Wat zocht de user / wat klikte die aan? (keyword, ad-copy, email-subject)
   - Message-match: is wat user verwachtte = wat ze zien?
   - Device-split: mobile-first ontwerpen als >50% mobile

2. **Boven-de-fold architectuur**:
   - Value-prop in 5-second test leesbaar
   - Primary CTA direct zichtbaar (niet alleen header-CTA)
   - Social proof of trust-signal binnen hero-bereik
   - Directional cue naar CTA (oog-gericht, arrow, whitespace)
   - Benefit-framed hook, niet feature-dump

3. **Copy-framework kiezen** (zie hieronder):
   - AIDA voor e-com product-LPs
   - PAS voor problem-oplossend B2B
   - AICPBSAWN voor complexe hoog-commitment
   - 4U voor tijdsgevoelige campagnes

4. **Friction-audit**:
   - Formulieren: doel-veld-count ≤ 4 voor eerste-interactie
   - Navigatie: LP = geen header-nav (houd in conversion-flow)
   - Afleidingen: social-icons, blog-links: vermijd boven fold
   - Loading: LCP < 2.5s verplicht; zwaar hero-video kan kapotmaken

5. **Psychologische triggers** inbouwen:
   - Social proof: reviews, klant-logos, testimonials met gezicht+naam
   - Scarcity/urgency (alleen waar echt van toepassing)
   - Authority: awards, certificaten, media-features
   - Reciprocity: gratis guide/checklist in exchange for email
   - Commitment/consistency: micro-yeses bouwen naar hoofdactie

6. **Mobile-first validatie**:
   - Thumb-zone: CTA bereikbaar met duim
   - Tap-targets ≥ 44×44px
   - Geen hover-only interacties
   - Sticky-CTA-bar overwegen bij langere LP's
   - Viewport-test op echte devices (Chrome DevTools is startpunt, niet eindpunt)

## Kern-kennisgebieden (2026 best practices)

### Copywriting frameworks (kies op basis van LP-doel)

**AIDA** (Attention-Interest-Desire-Action): e-com productpagina's
1. Attention: scherpe headline die probleem/verlangen aanspreekt
2. Interest: benefit-driven subheadline + hero-visual
3. Desire: product-voordelen, social proof, transformatie
4. Action: single duidelijke CTA

**PAS** (Problem-Agitate-Solution): problem-aware audience, B2B
1. Problem: benoem specifiek pijnpunt (klant herkent zich)
2. Agitate: vergroot kosten van niet-oplossen
3. Solution: positioneer aanbod als oplossing

**AICPBSAWN** (lange-form, hoog-commitment)
Attention → Interest → Credibility → Proof → Benefits → Scarcity → Action → Warning → Now
Voor duurdere producten, coaching, B2B high-ticket

**4U** (Urgent, Unique, Useful, Ultra-specific): headlines
Snelcheck: is je headline urgent? Uniek? Nuttig? Ultra-specifiek?

**Before-After-Bridge**: coaching / transformation products
1. Before: huidige situatie van de klant
2. After: gewenste toekomst
3. Bridge: jouw product/dienst als pad

### Form-optimalisatie (grootste hefboom)

- **11 → 4 velden = tot 120% completion-lift** (HubSpot studies, 2026 bevestigd)
- Verplichte velden minimaliseren
- Progressive profiling: laat email + 1 veld zien; verzamel rest bij latere touchpoints
- Social-login (Google, Apple) overwegen: halveert friction
- Inline validation (geen blokkerende errors na submit)
- Auto-fill vriendelijk (correct HTML input-types, autocomplete attributes)
- Verwijder: Phone (optioneel), Company Size (optioneel), Address fields (tenzij verzend)

### CTA-copy benchmarks

- **Specifieke voorbeelden van lift**:
  - "Sign up for free" → "Trial for free" = +104% (Unbounce case)
  - "Submit" → "Get my free guide" = typisch +20-40%
  - "Buy now" → "Add to cart" op PDP = vaak beter bij twijfel-traffic
- Regel: CTA beschrijft wat user krijgt, niet wat ze moeten doen
- Urgency-variant alleen bij echte urgency ("Claim today's price")
- 1 primary CTA boven fold, herhaal elke 1-2 scroll-posities

### Trust-signals hiërarchie

1. Klant-logos (top 3-6 bekende logos)
2. Reviews/ratings (aggregate + specifieke quotes)
3. Media-mentions ("as seen in")
4. Certifications / security badges
5. Money-back-guarantee of risico-reversal
6. Telefoonnummer + KvK + adres (NL-vertrouwen)

### Mobile-LP specifics

- Hero-tekst 1 zin, subkop 1 zin, CTA direct
- Geen side-by-side layouts (stacken)
- Sticky-CTA na scroll (niet vanaf het begin: ruk)
- Form-velden één-per-rij, nooit kolom-layouts op mobile
- Image-compression aggressief (WebP, responsive sizes)

### LP voor Google Ads (message match + Quality Score)

- Exact-match: keyword in H1 of direct daaronder
- Ad-copy belofte = LP-headline (geen verrassing)
- Snelheid: LCP < 2.5s (Quality Score-factor)
- Mobile-friendly verplicht
- Relevantie: geen generieke homepage als LP
- Privacy-policy + cookie-consent zichtbaar

### LP voor Meta Ads (post-click continuïteit)

- Visual continuïteit: LP-hero matcht ad-creative-stijl
- Emotionele hook van ad uitwerken in body
- Mobile-first (Meta-traffic is 90%+ mobile)
- Retargeting-LPs kunnen langer/gedetailleerder (warmer traffic)

### 5-second test

- Toon LP 5 sec, vraag user: wat biedt deze pagina? Voor wie?
- Als antwoord vaag → hero faalt
- Doe dit met 10 non-users: Maze/Useberry heeft dit als template

### Directional cues

- Oog-richting in hero-foto (naar CTA)
- Arrows / lines naar CTA
- Contrast-kleur alleen voor primary-CTA (niet overal)
- White-space rondom CTA groter dan rest

### Anti-patterns

- Homepage als LP voor specifieke campagne
- Carousel/slider in hero (verlaagt CVR 5-15%)
- Multiple CTAs die concurreren
- Navigation-header als LP: traffic lekt
- Stockfoto's zonder mensen (emotie verloren)
- "Learn more" als CTA (geen belofte)
- 10+ formuliervelden op eerste interactie
- Generieke headlines ("Welcome to our platform")

## Output-formaat

Skelet voor de landingspagina-blauwdruk, gebaseerd op de LP-brief hierboven:

```markdown
# LP-blauwdruk: [klant], [campagne]
1. Doel-conversie + primary metric
2. Audience: awareness-stage en segment
3. Traffic-source(s) en message-match
4. Value proposition
5. Copy-framework: AIDA, PAS, AICPBSAWN of 4U, met rationale
6. Secties-overzicht: hero, proof, FAQ, CTA
7. Design-specs: wireframe of Figma-link
8. Tech-specs: LCP-target, mobile-breakpoints
```

## Tips

- **5-second test verplicht** vóór klant-delivery. Als 10 testers de pitch niet snappen → herschrijven.
- **Form-velden reduceren = grootste lift-hefboom**. Elke verwijderd veld = merkbare CVR-lift.
- **Specificatie > vaagheid**. "Bespaar 4 uur per week" verslaat "werk efficiënter", altijd.
- **Mobile-first ontwerpen**, desktop volgt. Niet andersom, zelfs als 50/50 split.
- **Social proof boven fold**. Logos/reviews/ratings binnen eerste scherm = trust-trigger direct.
- **1 primary CTA**. Meerdere CTAs = keuzeverlamming. Secundaire acties secundair (tekst-link, niet knop).
- **CTA-copy benefit-focused**. "Start my free trial" > "Sign up". Beschrijf wat user krijgt.
- **LCP < 2.5s niet optioneel**. Snelheid = SEO + CVR + Quality Score. Bespaar niet op hero-image-compression.
- **LP zonder nav-header**. Traffic gekocht met doel → houd user in flow. Nav = ontsnappingsroute.
