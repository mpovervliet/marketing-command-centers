# Framer Development Specialist

Framer is in 2026 de rising star voor marketing + brand-launch sites. Voordeel tegenover Webflow: motion + React-component-integratie + blazing performance. Nadeel: minder CMS-diep, geen native ecommerce. Deze skill dekt site-structuur, Smart Components, code-components, CMS, Effects, Localization, en integraties.

---

## Wanneer activeren

- Brand-launch / product-launch-site (hero-heavy)
- Marketing-site met sterke motion-requirements
- Portfolio / agency / designer-studio
- Startup-landingpagina (snelle iteratie)
- Site waar React-componenten nodig zijn (custom widgets)
- Blog + case-studies via Framer CMS
- Multi-taal-site (Localization native)
- A/B-testing via third-party tools op Framer-site
- Framer-audit / bestaande site optimaliseren

## Werkwijze

### 1. Framer vs alternatieven (beslissings-framework)

Kies **Framer** als:
- Motion-rich merk-ervaring gewenst
- Designer-team (Figma-stijl workflow)
- Snelle time-to-market
- Light-CMS-needs (<1000 items)
- React-components gewenst voor custom widgets
- CWV-excellence out-of-the-box nodig

Kies **Webflow** als:
- Zwaarder CMS-needs
- Complexer content-modeling
- Logic-workflows
- Auth met Memberstack native
- Light-e-com binnen same tool

Kies **Shopify** voor serieus e-com (Framer + Shopify voor marketing + commerce split is valide stack).

### 2. Site-structuur & componenten

**Pages**: statische routes (/, /about, /pricing, /contact)

**CMS**: dynamische routes:
- Collections met fields
- Template-pagina's per collection
- SEO per item
- Max ~2000 items comfortabel (afhankelijk van plan)

**Components** 3 lagen:
- **Framer Components**: native building blocks
- **Smart Components**: responsive + variants + interactive states (vergelijkbaar met Figma Components)
- **Code Components**: React-componenten (JSX/TSX) voor custom functionality

### 3. Smart Components (native power)

- **Variants** per component (primary/secondary, light/dark)
- **Breakpoints** per variant (desktop/tablet/mobile)
- **Interactive states** (hover, pressed)
- **Link props** voor dynamisch content
- **Conditional visibility** binnen component
- **Reusable across pages**: centralized updates

### 4. Code Components (React)

- JSX/TSX schrijven direct in Framer
- Props met control-types (text, number, boolean, color, etc.)
- Imports van NPM beschikbaar (bundled in build)
- Shared state via React Context als nodig
- Auto-detectie van component-props door Framer-editor
- Use-cases: custom calculators, 3D-viewers, complex form-logic, API-integraties

### 5. CMS-strategie

- **Collections** per entity (Blog, Case Study, Team)
- **Fields**: text, rich text, image, number, date, reference, file, boolean
- **Reference fields** voor relaties
- **Search + filter** via Smart Components
- **Import via CSV** of Notion-sync
- **API**: Framer CMS-API beschikbaar voor sync met externe systemen

### 6. Effects & Interactions (2026-power)

- **Effects**: scroll-driven animations, reveal-on-scroll, parallax
- **Interactions**: click/hover/drag/swipe/keypress triggers
- **Transitions**: page-transitions (smooth SPA-feel)
- **Appear-animations** per component
- **Cursor effects** voor brand-magic
- Performance: native-optimized (GPU, requestAnimationFrame)

### 7. Localization (native)

- Multi-locale per project
- Per-page + per-component translatie
- AI-translation + manual-edit
- URL-structuur: subdirectory (`/en/`, `/nl/`) default
- Hreflang automatisch
- Locale-aware CMS-content

### 8. Forms

- **Native Framer Forms**: basis
- **Integraties**: HubSpot, Mailchimp, Klaviyo, ConvertKit, Google Sheets, webhook
- **Custom form logic** via code-component als complex

### 9. SEO op Framer

- Meta per pagina editable
- Schema via custom-code-injection (head)
- Sitemap auto-generated
- 301-redirects via Site-settings (beperkt, ook via Cloudflare)
- Canonicals default
- Open Graph + Twitter cards per pagina
- CWV excellent default (minimale JS-overhead)

### 10. Performance (CWV-default excellent)

- Native image-optimization (WebP/AVIF)
- Lazy-load default
- Minimale JS overhead
- Edge-hosting default
- Fonts: Google Fonts + self-host optie
- Code-components kunnen CWV raken (audit per component)

## Kern-kennisgebieden (2026 best practices)

### Framer AI (2024-2026)

- **AI-generate site**: prompt-to-site
- **AI-design**: component-variants via prompt
- **AI-copy**: content-generatie
- **AI-translate**: Localization-support
- First-pass-tool; human-edit altijd
- Altijd: brand-consistency > AI-output

### Hosting + domains

- Framer hosting = edge-first (CDN)
- Custom domain via CNAME
- Gratis SSL
- Pro-plan voor serieuze sites
- Business-plan voor multi-site-agencies

### Integraties-stack (2026-stack)

- **Analytics**: GA4, Plausible, Fathom, Vercel Analytics: via head-code-injection
- **CRM**: HubSpot, Salesforce, Pipedrive via forms of webhooks
- **Email**: Mailchimp, Klaviyo, ConvertKit, Resend
- **Payment**: Stripe via custom code-component
- **Chat**: Intercom, Crisp, HelpScout (audit CWV-impact)
- **A/B-test**: VWO, AB Tasty, Convert via custom-code

### Limitations & workarounds

- **Geen native e-com** → integreer Shopify via subfolder of subdomain
- **Beperkte Logic** (t.o.v. Webflow Logic) → Zapier/Make ernaast
- **CMS-limits** rond 2000 items comfortabel
- **Geen native auth** → Memberstack / Clerk via code-component
- **Schema handmatig** → JSON-LD in head
- **Beperkte redirects** → Cloudflare-proxy

### Accessibility op Framer

- Aria-attributes via code-components injecteerbaar
- Focus-styles per component
- Keyboard-nav testen (effects niet tab-trap)
- Alt-text per image verplicht
- Reduced-motion: effects respect via code-component

### Anti-patterns

- Code-components met ongeoptimaliseerde deps (CWV-impact)
- Alle effects overal (motion-overload + reduced-motion-schending)
- CMS-misbruik als database (>2000 items)
- Custom schema vergeten (SEO-loss)
- Framer voor serieus e-com (verkeerd platform)
- Geen brand-tokens → design-drift tussen pages
- Animaties zonder reduced-motion-variant
- Hero-animaties die LCP vertragen

## Tips

- **Framer voor marketing-sites**. Best-in-class motion + performance.
- **CMS voor light content**. <2000 items; groter = verkeerd platform.
- **Smart Components > hand-matched design**. Variants + breakpoints centraal.
- **Code-components spaarzaam**. Elke custom-component = CWV-risk + maintenance.
- **Effects met discipline**. Motion-overload = conversie-killer + a11y-fail.
- **Framer + Shopify = valide stack**. Framer voor marketing, Shopify voor shop.
- **Localization native**. Geen hack met meerdere sites.
- **AI als first-pass**. Brand-consistency wint altijd.
- **Custom schema-injection verplicht**. Framer regelt het niet; jij moet.
- **Pro-plan minimum**. Business voor serieus werk.
