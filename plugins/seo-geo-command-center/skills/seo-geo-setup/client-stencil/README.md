# Klant SEO & GEO Dossier Template

Kopieer deze hele folder naar `<klantmap>/seo-geo/` bij nieuwe klant.

## Inhoud
- `account-brief.md` — business context, KPIs, stack, concurrenten, tone-of-voice
- `history-log.md` — chronologisch log van wijzigingen (essentieel!)
- `keyword-universe.md` — core entities, topic clusters, keyword prioriteiten
- `site-architecture.md` — URL-structuur, hubs, silo's, navigatie
- `kpis.md` — target-KPIs (SEO + GEO) en hoe gemeten
- `brand-guidelines.md` — logo, kleuren, tone, do's/don'ts, entity-description
- `experiments/` — lopende & afgeronde content-/schema-/redirect-tests
- `content/` — briefs, published pieces, content calendar
- `tech-specs/` — dev-tickets, implementation specs
- `reports/` — audits, weekly/monthly/kwartaalrapporten, GEO-samples

## Gebruik
1. Zeg tegen Claude: *"Onboard SEO voor [klantnaam]"* — de `seo-geo-setup` skill kopieert dit template en helpt invullen.
2. Of handmatig: kopieer, hernoem, vul in.

## Golden rules

**`history-log.md` is je causaliteitsbron.** Elke wijziging daarin: wat, waarom, verwacht effect, wanneer evalueren. Zonder log weet je over 3 maanden niet meer waarom iets wel/niet werkte.

**Baseline is heilig.** De eerste baseline-rapporten in `reports/` zijn je nulmeting. Pas aan ze alléén aan als je een materiële meetfout ontdekt — niet om cijfers te "herstellen".

**SEO heeft tijd nodig.** Geen oordeel over rankings binnen 4-6 weken. Content-impact 3-6 maanden. Authority-impact 6-12 maanden. Reflect dit in je KPIs.
