# marketplaces-command-center

MP's Marketplaces Command Center — 3 skills voor verkopen via Amazon en bol: marketplace-specialist (kanaalstrategie, P&L per kanaal, fulfilment FBA/LVB, kanaal-conflict), bol-retail-media (listings, Buy Box, Sponsored Products, servicenormen) en amazon-seo-listings (COSMO/Alexa-for-Shopping tijdperk, backend-attributen, A+ content). Werkt generiek met elke klantmap.

## Skills in deze plugin

- `marketplace-specialist`
- `bol-retail-media`
- `amazon-seo-listings`

Gegenereerd door `build-plugins.py` uit `skills-source/`.
