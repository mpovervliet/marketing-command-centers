# social-content-command-center

MP's Social Content Command Center — 3 skills voor organic social van klant-merken: master-specialist (kanaal-keuzekader, contentpijlers, social-naar-email capture), short-video playbooks (TikTok/Reels/Shorts: hooks, formats, video-zoekgedrag) en community-management (DM/comment-funnels, Instagram-comment-naar-opt-in via Klaviyo, moderatie en crisis-protocol). Werkt generiek met elke klantmap.

## Skills in deze plugin

- `social-content-specialist`
- `short-video-content`
- `social-community-management`

Gegenereerd door `build-plugins.py` uit `skills-source/`.
