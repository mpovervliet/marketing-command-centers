# hospitality-command-center

MP's Hospitality Command Center: 6 skills voor horeca, venues en kleinschalig verblijf: hospitality-guest-crm (gastdata-activatie, soft opt-in artikel 11.7 Tw, re-permission, reactivatie-segmenten), hospitality-reputation-reviews (respons-ritme, thema-monitoring, AI-review-summaries), giftcard-voucher-marketing (cadeaubon-programma, decemberpiek, NL-kanaalkeuze), stay-camping-distribution (kanaal-mix en launch voor stadscampings en bijzonder verblijf), local-media-city-marketing (hyperlokale pers en city-marketing-partnerships) en corporate-offsites-wellbeing (heidagen en wellbeing-dagen als B2B-productlijn). Werkt generiek met elke horeca/venue-klantmap.

## Skills in deze plugin

- `hospitality-guest-crm`
- `hospitality-reputation-reviews`
- `giftcard-voucher-marketing`
- `stay-camping-distribution`
- `local-media-city-marketing`
- `corporate-offsites-wellbeing`

Gegenereerd door `build-plugins.py` uit `skills-source/`.
