# dashboarding-command-center

MP's Dashboarding & Data Command Center: 15 skills voor de rapportage- en beslislaag over alle kanalen heen: dashboard-specialist (router, tool-keuze), looker-studio-builder, analytics-bigquery-sql (GA4-export als datalaag), kpi-framework-design (metric-bomen, targets, alerts), cowork-live-dashboards (live artifacts op MCP-data), dashboard-audit en marketing-data-analyst (AI-gedreven analyse, anomalie-detectie, seizoenspatronen). Werkt generiek met elke klantmap.
