# affiliate-marketing-command-center

MP's Affiliate Marketing Command Center: 4 skills voor affiliate als kanaal voor NL/EU e-commerce en leadgen: affiliate-marketing-specialist (router, kanaal-fit, netwerk-landschap), affiliate-program-setup (netwerk-keuze Daisycon/TradeTracker/Awin/Tradedoubler, commissiemodel, voorwaarden, launch), affiliate-publisher-management (werving, deals, fraude-detectie, sanctie-ladder) en affiliate-measurement-attribution (dedupe, keuring, incrementaliteit, netto-ROAS). Werkt generiek met elke klantmap.

## Skills in deze plugin

- `affiliate-marketing-specialist`
- `affiliate-program-setup`
- `affiliate-publisher-management`
- `affiliate-measurement-attribution`

Gegenereerd door `build-plugins.py` uit `skills-source/`.
