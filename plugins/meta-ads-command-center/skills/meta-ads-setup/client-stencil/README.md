# Klant Dossier Template — Meta Ads

Kopieer deze hele folder naar `<klantmap>/meta-ads/` bij nieuwe klant.

## Inhoud
- `account-brief.md` — business context, KPIs, tracking (Pixel/CAPI/Dataset), concurrenten, tone-of-voice
- `history-log.md` — chronologisch log van wijzigingen (essentieel!)
- `campaigns.md` — overzicht live campagnes + ad-set structuur-verantwoording
- `kpis.md` — target-KPIs en hoe ze gemeten worden
- `brand-guidelines.md` — logo, kleuren, tone, do's/don'ts (cruciaal voor Meta creative)
- `experiments/` — lopende & afgeronde A/B's en lift-tests
- `reports/` — audit, maandrapporten, ad-hoc analyses
- `creative/` — hooks-library, briefs, gegenereerde ad copy, asset-pool

## Gebruik
1. Zeg tegen Claude: *"Onboard nieuwe klant [naam] op Meta"* — de `meta-ads-setup` skill kopieert dit template en helpt invullen.
2. Of handmatig: kopieer, hernoem, vul in.

## Golden rules
- **`history-log.md` is je causaliteitsbron.** Elke wijziging daarin: wat, waarom, verwacht effect, wanneer evalueren.
- **`creative/hooks-library.md` is je creative-bron.** Bouw deze op vanaf dag 1 — dat is je iteratie-engine.
- **`account-brief.md` Pixel/CAPI sectie is non-negotiable.** Zonder werkende tracking is alles wat je doet meten met een liniaal vol scheuren.
