MP's B2B Marketing Command Center — 2 skills voor B2B-groei: LinkedIn Ads (Thought Leader Ads playbook, format-keuze, targeting-discipline 50k-500k, pipeline-meting) en B2B-leadgen/ABM-light voor MKB (ICP-definitie, buying committees, account-tiering, signaal-gedreven outreach, nurture met opvolg-SLA).

## Skills in deze plugin

- `linkedin-ads-b2b`
- `b2b-leadgen-abm`

Gegenereerd door `build-plugins.py` uit `skills-source/`.
