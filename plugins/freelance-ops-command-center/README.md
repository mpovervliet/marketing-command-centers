# freelance-ops-command-center

MP's Freelance Ops Command Center — 15 skills die het eigen freelance-proces versnellen: context-index per klantmap (CONTEXT_INDEX.md), client-intake & onboarding, wekelijkse klant-updates, offertes/proposals, QBR-builder, uren & facturen, knowledge-capture, LinkedIn personal brand, cross-channel competitor-teardowns, plus CV-tailoring, motivatiebrieven en vacature-analyse.
