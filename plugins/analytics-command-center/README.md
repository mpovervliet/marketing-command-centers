# analytics-command-center

MP's Analytics & Measurement Command Center — 15 skills voor het meetfundament onder alle kanalen: master-specialist (router), GA4/GTM-audit (60+ punten), meetplannen & datalayer-specs, server-side tagging met Consent Mode v2 (incl. de juni-2026 GA4-Ads consent-wijziging) en incrementality-testing (geo-holdouts, conversion lift, MMM-light) en consent/privacy-optimalisatie (banner-UX, CMP-audit, consent-rate als groei-KPI). Werkt generiek met elke klantmap.
