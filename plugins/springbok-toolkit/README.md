# springbok-toolkit

Springbok huisstijl-toolkit — 2 deliverable-generators: springbok-gdoc (professionele .docx documenten in Springbok-stijl) en springbok-slideshow (branded PowerPoint presentaties via PptxGenJS).

## Skills in deze plugin

- `springbok-gdoc`
- `springbok-slideshow`

Gegenereerd door `build-plugins.py` uit `skills-source/`.
