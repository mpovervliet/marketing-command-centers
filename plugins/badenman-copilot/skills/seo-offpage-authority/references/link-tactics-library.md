## Tactic 1: Digital PR — Data-gedreven Campagnes

**Wat:** Publiceer origineel onderzoek, enquêtedata, of een uniek dataset dat journalisten willen citeren.

**Hoe:**
1. Identificeer een vraag die journalisten in jouw niche regelmatig stellen
2. Verzamel data (eigen klantdata, enquête via Surveymonkey, publiekedata CBS/RDW/AFM)
3. Schrijf een persbericht + volledig rapport
4. Outreach naar Tier-1 en Tier-2 journalisten (zie nl-media-matrix.md)
5. Timing: koppel aan actualiteit (bijv. energieprijzen in winter, autoverzekering in januari)

**Template Persbericht:**
```
[MERK] ONDERZOEK: [PROVOCERENDE BEVINDING IN ÉÉN ZIN]

[Stad], [Datum] — [MERK] heeft onderzoek gedaan onder [N respondenten / databron] en ontdekte dat [key finding].

[2e paragraph: context en implicatie]
[3e paragraph: quote van woordvoerder]
[4e paragraph: methodologie]

Over [MERK]: [2 zinnen boilerplate]
Contactpersoon: [Naam] | [Email] | [Tel]
```

## Tactic 2: Broken Link Building

**Wat:** Vind kapotte links op relevante pagina's en bied jouw content als vervanging aan.

**Hoe (met web search):**
1. Zoek: `[jouw niche] "broken link" OR "404" site:[targetdomein]`
2. Of gebruik Ahrefs → Site Explorer → Broken backlinks van competitor
3. Identificeer welke content er linked was (Wayback Machine)
4. Maak gelijksoortige of betere content
5. Outreach: "Ik zag dat je linkt naar [gebroken URL], ik heb een bijgewerkte versie"

**Outreach template:**
```
Onderwerp: Kapotte link op [PAGINA_TITEL]

Hoi [NAAM],

Ik las net je artikel over [ONDERWERP] en zag dat de link naar [GEBROKEN_URL] niet meer werkt.

Ik heb onlangs een bijgewerkte gids geschreven over hetzelfde onderwerp: [JOUW_URL]

Zou dat een goede vervanging zijn?

Groet,
[NAAM]
```

## Tactic 3: Resource Page Outreach

**Wat:** Veel websites onderhouden "handige links" of "resources" pagina's. Jouw content erop krijgen = gratis redactionele link.

**Zoekstrings voor resource pages:**
```
[niche] "handige links" OR "nuttige links" OR "resources"
[niche] inurl:resources
[niche] inurl:links "aanbevolen"
[niche] "link toevoegen" OR "stel jouw site voor"
```

## Tactic 4: HARO / Qwoted / ProfNet

**Wat:** Journalisten zoeken experts voor quotes. Reageer met een citeerbare expert-quote.

**Platforms:**
- Qwoted.com (internationaal, gratis voor experts)
- ProfNet (internationaal, betaald)
- #JournoRequest op Twitter/X (UK-heavy maar ook NL)
- PersService.nl (NL, persbureaus)

**Quote aanpak:**
- Kort (max 3 zinnen)
- Eén concrete statistiek of feit erin
- Eindigt met implicatie voor de lezer
- Stuur binnen 1 uur van publicatie query

## Tactic 5: Competitor Link Intersect

**Wat:** Vind domeinen die linken naar meerdere concurrenten maar niet naar jou — dit zijn de meest kansrijke targets.

**Met Ahrefs:**
→ Link Intersect tool → voer 3–5 competitors in → exporteer resultaten → filter op DR > 30 + relevantie

**Zonder Ahrefs (web search):**
```
Zoek: link:[competitor1.nl] -site:[jouwdomein.nl]
Combineer met: link:[competitor2.nl]
```

## Tactic 6: Gastblogs op High-DA Sites

**Wanneer:** Alleen zinvol bij DA 50+ sites in jouw niche. Vermijd gastblog-netwerken.

**Prospectie:**
```
[niche] "schrijf voor ons" OR "gastblog" OR "bijdrage leveren"
[niche] "wil jij schrijven" OR "word auteur"
```

**Kwaliteitscheck:**
- Echte redactie? (controleer "over ons")
- Organisch verkeer? (check Ahrefs/Similarweb estimate)
- Gevarieerde auteurs? (niet alleen gastbloggers)
- Nofollow of dofollow?

## Tactic 7: Podcast Appearances

**Waarom off-page relevant:** Podcast-show-notes bevatten vaak dofollow links. Bovendien: transcripts worden gecrawld door AI-systemen (GEO-waarde).

**Aanpak:**
1. Zoek: `[niche] podcast Nederland` of `[niche] podcast site:spotify.com`
2. Check of show notes links bevatten
3. Pitch jezelf als gast: stuur 3 concrete gespreksonderwerpen + jouw expertise summary

## Tactic 9: Wikipedia & Wikidata

**GEO-impact: zeer hoog.** LLMs trainen zwaar op Wikipedia. Een Wikipedia-vermelding = verhoogde kans op AI-citatie.

**Aanpak:**
1. Controleer of jouw merk/product al een Wikipedia-pagina heeft
2. Zo ja: zorg dat de pagina actueel, neutraal en geciteerd is
3. Zo nee: beoordeel notability criteria (moet geciteerd zijn in onafhankelijke bronnen)
4. Wikidata entity aanmaken voor je merk (lager drempel dan Wikipedia-artikel)
5. Schema.org Organization markup op je homepage koppelen aan Wikidata QID

## Tactic 10: Testimonials & Case Studies

**Onderschat:** Lever een testimonial aan je tools/leveranciers/partners. De meeste B2B tools plaatsen deze op hun website met dofollow link.

**Script:**
```
Hoi [NAAM],

Ik gebruik [TOOL/DIENST] nu al [X maanden] en ben erg tevreden, met name vanwege [specifiek voordeel].

Graag zou ik een testimonial schrijven als jullie dat kunnen gebruiken op jullie website.

[Jouw naam + functietitel + bedrijf]
```

## Tactic 11: Sponsorships & Partnerships

**Typen:** events, awards, branche-organisaties, onderwijs (hogescholen, universiteiten), non-profits.

**Selectiecriteria voor links:**
- .edu of .org extensie = bonuspunten
- Relevantie boven DA: een .edu link van een automotive faculteit > een DA80 lifestyle site voor een autoverzekeraar
- Zoek: `[niche] sponsoren` of `[brancheorganisatie] partners`

## Tactic 12: Unlinked Brand Mentions

**Wat:** Jouw merk wordt online vermeld maar zonder link. Dit zijn de makkelijkste links om te claimen.

**Vinden:**
- Google Alerts op je merknaam
- Ahrefs → Alerts → Mentions
- Web search: `"[merknaam]" -site:[jouwdomein.nl]`

**Outreach:**
```
Onderwerp: Bedankt voor de vermelding van [MERK]!

Hoi [NAAM],

Ik zag dat je [MERK] vermeldde in je artikel [ARTIKEL_TITEL] — bedankt!

Zou je er ook een link naar [URL] bij willen zetten? Dan kunnen je lezers direct meer informatie vinden.

Groet,
[NAAM]
```
