# design-os-command-center

Het Design OS Command Center: 11 skills voor data-governed redesigns waarbij elke ontwerpkeuze herleidbaar is naar data (evidence → beslismoment → hypothese → richting → DDR → Figma → prototype → experiment → learning). Branche-, klant- en marktneutraal via acht parameters in 01_CONTEXT/Client-Profile.md. Skills: design-os-specialist (router, fase-gates), design-os-setup, design-os-evidence (Evidence Registry, Evidence Score), design-os-strategy, design-os-references, design-os-directions, design-os-hypotheses-ddr (DDR, ICE, Coverage Matrix), design-os-figma-build, design-os-prototype (klikbaar prototype, publicatie-poort), design-os-experience-motion (Story Spine, Motion Spec) en design-os-red-team (QA-poort met Gate-Records). Versiegeschiedenis: docs/CHANGELOG-design-os-command-center.md.
