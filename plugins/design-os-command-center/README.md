# design-os-command-center

MP's Design OS Command Center: 7 skills voor data-governed redesigns waarbij elke ontwerpkeuze herleidbaar is naar data (evidence → hypothese → DDR → Figma → experiment → learning): design-os-specialist (router, fase-gates), design-os-setup (intake plus client-stencil met de volledige 00-11 projectstructuur en agent-prompts), design-os-evidence (data-baseline, Evidence Registry, Measurement-QA), design-os-references (Refero/Mobbin cross-industry bewijs), design-os-hypotheses-ddr (Design Decision Records, ICE, Coverage Matrix), design-os-figma-build (wireframes, hi-fi richtingen, design tokens via Figma MCP) en design-os-red-team (onafhankelijke QA-poort plus learning-loop). Gegeneraliseerd uit de eerste volledige case, juli 2026. Werkt generiek met elke klantmap.

## Skills in deze plugin

- `design-os-specialist`
- `design-os-setup`
- `design-os-evidence`
- `design-os-references`
- `design-os-hypotheses-ddr`
- `design-os-figma-build`
- `design-os-red-team`

Gegenereerd door `build-plugins.py` uit `skills-source/`.
