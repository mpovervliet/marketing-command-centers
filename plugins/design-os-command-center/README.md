# design-os-command-center

Het Design OS Command Center: 9 skills voor data-governed redesigns waarbij elke ontwerpkeuze herleidbaar is naar data (evidence -> beslismoment -> hypothese -> richting -> DDR -> Figma -> experiment -> learning). Branche-, klant- en marktneutraal: het systeem past zich aan via acht parameters in 01_CONTEXT/Client-Profile.md. design-os-specialist (router, fase-gates), design-os-setup (intake plus client-stencil), design-os-evidence (data-baseline, Evidence Registry, Measurement-QA), design-os-strategy (conversion architecture, beslismomenten), design-os-references (cross-industry patroon-bewijs plus stijl-scouting), design-os-directions (onderbouwde ontwerprichtingen in geisoleerde parallelle subagents), design-os-hypotheses-ddr (Design Decision Records, ICE, Coverage Matrix), design-os-figma-build (wireframes, hi-fi, design tokens) en design-os-red-team (afdwingbare QA-poort met Gate-Records plus learning-loop). In 0.5.0: de Evidence Score meet bewijskracht via een ankermodel in plaats van bronbreedte, en de nieuwe parameter traject-omvang (vol/light) schaalt het volume van een traject zonder een enkele kwaliteitsregel te raken.
