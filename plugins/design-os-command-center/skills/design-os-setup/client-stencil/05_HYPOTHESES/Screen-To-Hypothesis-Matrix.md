# Screen-to-Hypothesis Matrix
Versie: 0.1 (stencil)
Status: TEMPLATE, invullen bij intake

Doel: de brug tussen strategie en Figma. Elke rij is een direct-uitvoerbare design- of copy-actie. Intern document, niet client-facing.
Relatie: werkt samen met `06_DESIGN/Wireframe-Brief-Template.md` en `05_HYPOTHESES/Hypothesis-Backlog.md`.

## Aanpak

Elke component op elk scherm moet terug te voeren zijn op:
1. Een beslismoment (BM-X, uit `04_STRATEGY/Decision-Moment-Map.md`)
2. Een hypothese (H-XX)
3. Een bewijsbron (interne data / competitive / cross-industry, met E-IDs)
4. Een primaire KPI
5. Een guardrail (wat mag NIET verslechteren)
6. Het bijbehorende experiment (EXP-XX)

Rijen sorteren op pagina, dan op prioriteit (hoog > middel > laag).
