# Content-Handoff [KLANT]
Versie: 0.1 (stencil)
Status: TEMPLATE, invullen in fase 9

Doel: definitieve copy per page-type opleveren, conform `01_CONTEXT/Brand-Context.md`
(tone-of-voice, verboden woorden, wettelijke verplichte teksten uit P5). Geen "lorem" of
placeholder-tekst gaat live; structuurkeuzes in fase 7 zijn al op echte contentlengtes
gebaseerd, dus de definitieve copy past in het ontwerp zoals het is opgeleverd.

## Format per scherm

```
Scherm: [Template-ID, naam]
Component: [C-XX, indien copy component-specifiek is]
Definitieve tekst:
  [Kop]: [...]
  [Subkop]: [...]
  [Body]: [...]
  [CTA]: [...]
Bronvermelding/goedkeuring: [wie heeft dit geaccordeerd, datum]
Wettelijk verplicht: [ja/nee — zo ja, welke tekst is verplicht en waarom (P5)]
```

## Voorbeeld (fictief, generiek)

```
Scherm: T2 Prijs-/pakketpagina
Component: C-01_ValuePropHero_DDR-H8-01
Definitieve tekst:
  Kop: Weet binnen 1 minuut wat het jou kost
  Subkop: Geen verrassingen achteraf, ook niet bij afwijkende situaties
  CTA: Bereken jouw prijs
Bronvermelding/goedkeuring: [KLANT]-marketingmanager, [datum]
Wettelijk verplicht: nee
```

## Definitie van Done

Elke tekst in de opgeleverde schermen is definitief, geaccordeerd en getoetst aan
`01_CONTEXT/Brand-Context.md`; wettelijk verplichte teksten (P5) zijn expliciet
aangemerkt en niet per ongeluk weggelaten of ingekort.
