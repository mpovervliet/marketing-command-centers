# ai-creative-studio-command-center

MP's AI Creative Studio Command Center: 4 skills voor AI-creative-productie op schaal (Andromeda en PMax vragen 10-15 concepten per campagne): ai-video-ads (Veo/Kling/Runway productie-workflows), ai-image-production (Midjourney/Nano Banana/FLUX pipelines, productfotografie-regels), ai-ugc-avatar (avatar-UGC met AI Act Art. 50 disclosure) en creative-qa-brand-gate (verplichte kwaliteitspoort: brand, artefacten, claims, rechten, disclosure, platform-policy). Concept-strategie blijft bij de ads-centers.

## Skills in deze plugin

- `ai-video-ads`
- `ai-image-production`
- `ai-ugc-avatar`
- `creative-qa-brand-gate`

Gegenereerd door `build-plugins.py` uit `skills-source/`.
