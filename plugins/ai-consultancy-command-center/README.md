# ai-consultancy-command-center

MP's AI-Consultancy Command Center — 6 skills voor AI-consultancy bij MKB en marketing-teams: master-specialist (adoptie boven tooling, use-case-first, champions-model), AI-adoptie-audit en use-case-discovery, EU AI Act compliance-ondersteuning (Art. 50 transparantie per aug 2026, high-risk via Omnibus uitgesteld naar dec 2027), AI-trainingen en workshops, AI-toolstack-advies en team-promptbibliotheken. Werkt generiek met elke klantmap.

## Skills in deze plugin

- `ai-consultant-specialist`
- `ai-adoption-audit`
- `ai-act-compliance`
- `ai-training-workshops`
- `ai-tool-stack-advisor`
- `prompt-library-builder`

Gegenereerd door `build-plugins.py` uit `skills-source/`.
