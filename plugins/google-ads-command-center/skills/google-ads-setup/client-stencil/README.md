# Klant Dossier Template

Kopieer deze hele folder naar `clients/<klant-slug>/` bij nieuwe klant.

## Inhoud
- `account-brief.md` — business context, KPIs, tracking, concurrenten, tone-of-voice
- `history-log.md` — chronologisch log van wijzigingen (essentieel!)
- `campaigns.md` — overzicht live campagnes + structuur-verantwoording
- `kpis.md` — target-KPIs en hoe ze gemeten worden
- `brand-guidelines.md` — logo, kleuren, tone, do's/don'ts
- `experiments/` — lopende & afgeronde experiments
- `reports/` — audit, maandrapporten, ad-hoc analyses
- `creative/` — creative briefs en gegenereerde ad copy

## Gebruik
1. Zeg tegen Claude: *"Onboard nieuwe klant [naam]"* — de `google-ads-setup` skill kopieert dit template en helpt invullen.
2. Of handmatig: kopieer, hernoem, vul in.

## Golden rule
**`history-log.md` is je causaliteitsbron.** Elke wijziging daarin: wat, waarom, verwacht effect, wanneer evalueren. Zonder log weet je over 3 maanden niet meer waarom iets wel/niet werkte.
